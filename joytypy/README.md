# 敲敲乐（JoyTypy）

面向小学 1-3 年级儿童的**拼音打字练习应用**。孩子看着完整诗句、在电脑键盘或页面键盘上敲出对应拼音，建立"拼音字母 ↔ 物理键位"映射，同时完成识字与课文诵读。

**特点**：练习数据留在当前设备的浏览器里、无系统输入法、无广告、无账号。静态网页版首次打开需联网；成功缓存后可离线练习。

---

## 快速开始

### 分享给家长群：静态网页版

将 `joytypy/` 内的应用文件发布到支持 HTTPS 的静态网站，分享固定网址即可；家长无需安装 Node.js，也无需启动服务。建议一直使用同一个网址和浏览器，因为浏览器按网站地址分别保存进度。内置课文见 `lessons/catalog.json`；新增内置课文时须同步更新该目录和 `service-worker.js` 的缓存清单。

家长打开链接后，在首页点“导入课文”选择 `.txt` / `.md` 文件，可一次选多篇；导入的课文只在当前浏览器可见。电脑可用实体键盘，手机可点页面键盘。设置页“导出全部数据”会下载含档案、练习进度、报告原始记录、校对结果和导入课文的 JSON 备份；换设备时在新设备打开同一网址，再点“导入备份”。导入前应用会先下载当前数据备份，然后恢复所选备份。换浏览器、清理网站数据或更换网址前，请先导出备份。报告导出只包含报告文本，不能用于恢复进度。

**发布前验收**：在目标 HTTPS 网址打开页面，确认三篇内置课文可读；断网后重新打开仍能练习；导入一篇课文、练到一半、刷新续练；导出备份后在另一浏览器导入，确认课文和进度恢复。应用未配置任何上传接口；静态网站服务商仍会收到正常的网页访问请求。尚未绑定正式网址时不要直接转发本机的 `127.0.0.1` 地址给其他家长。

### 本机开发方式

### 1. 放入课文（可选）

把想练的诗词/短文存成 `.txt` 或 `.md`，放进 `lessons/` 文件夹，或在网页里点“导入课文”（已内置《静夜思》《春晓》《琵琶行》）。

### 2. 启动

- **Mac**：双击 `start.command`
- **Windows**：双击 `start.bat`
- **命令行**：`node server.js`（需 Node.js 18+）

浏览器会自动打开 `http://127.0.0.1:5173`。应用固定使用 5173 端口，因为浏览器会按“地址 + 端口”隔离本地进度。若提示端口被占用，请先检查这个地址是否已有敲敲乐页面；若不是，关闭占用端口的程序再启动。应用不会自动换端口，也不会清除旧端口上的数据。

### 3. 使用

1. 首次打开会引导创建一个练习档案（输入昵称 + 选头像）。
2. 在设置中选择默认模式，在首页选择课文。
3. 若当前段含多音字，家长按课文中的出现位置确认读音；长文每 12 字为一段，后续段到达时再校对。结果按课文保存，多个孩子共用。
4. 进行中的课文再次打开时，可选“继续”或“从头开始”。进度按孩子、课文和模式保存，敲到当前字母的进度也会保留。
5. 星星按每个完成字即时累计，每次重练仍可获得；每篇课文的首次完成徽章每位孩子只发一次。

### 4. 退出

- 应用内点"退出"按钮，或
- 双击 `stop.command`（Mac）/ `stop.bat`（Win），或
- 直接关闭启动时的终端窗口。

> 服务器空闲 30 分钟会自动退出，避免进程常驻。

## 三种练习模式

| 模式 | 屏幕显示 | 训练重点 |
|------|----------|----------|
| **键位启蒙** | 当前诗句跟随高亮 + 应敲字母 + 键盘 | 字母 ↔ 位置 |
| **拼音双练** | 当前诗句跟随高亮 + 汉字及带声调拼音 | 拼音 + 键位 |
| **识字诵读** | 当前诗句跟随高亮 + 大字号汉字及拼音 | 识字 + 内容 |

练习时保留完整诗句及标点、换行；已敲的字变绿，当前字高亮。敲到下一句时整句切换。没有句号的长段会按换行和长度分段，避免把整篇课文挤在一屏。

三模式共享同一"逐字母比对"内核，可在设置中切换默认模式。

## 课文格式

### 推荐：纯文本

直接写中文即可，引擎自动转拼音：

```
床前明月光，
疑是地上霜。
```

多音字会自动检测，分段弹出校对面板供家长点选。同字在不同位置可以选不同读音。

### 高级备选：手写拼音覆盖

**行内标注**（一个汉字配一个括号）：

```
银(yin)行(hang) 的 业务 很 多。
```

**头部映射表**（适合全篇多音字）：

```
---
行: hang
重: chong
---
远上寒山石径斜，
```

> 优先级：当前位置的行内标注 > 头部映射 > 按位置保存的校对结果 > 词典默认。头部映射作用于该字的每次出现。

## 多用户档案

支持创建多个儿童档案（昵称 + 头像 emoji），各档案独立保存进度、星星、小红花、成就。首页可一键切换。

---

## 家长报告

家长报告页分别展示本周按键正确率（正确按键 ÷ 全部按键）和单字首次敲对率（从未敲错的完成字 ÷ 完成字），并展示当前已练课文的平均完成率、成就与累计奖励。趋势基于真实按键记录；旧版数据没有按键记录时显示“暂无记录”，不拿完成率代替。支持导出文本和打印。

---

## 技术说明

- 前端：原生 HTML + CSS + JavaScript（ES2020+），零构建、无框架
- 拼音引擎：pinyin-pro（本地 vendor，离线运行）
- 服务器：Node.js（零依赖，仅监听 127.0.0.1）
- 存储：localStorage（按档案隔离，支持 JSON 备份）；课程导入保存在当前浏览器
- 分发：可作为 HTTPS 静态网页/PWA 发布；保留 Node 本地启动供开发与离线文件夹管理
- 测试：Vitest

### 运行测试

```bash
npm install
npm test
```

## 隐私

所有数据（进度、奖励、档案、校对结果、导入课文和练习统计）仅存于当前浏览器的 `localStorage`，应用不上传这些内容。无第三方 SDK、无广告。首次打开静态网页版和获取应用更新需要联网；浏览器、设备或网址变化会使用不同的本地存储空间，旧地址的数据不会被应用自动删除或迁移。请定期导出备份，尤其在换设备或清理浏览器前。
